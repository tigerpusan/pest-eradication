- 실전형 아트 시스템
- 홈 / 플레이 / 결과 UI 완성형 정리
- 파리 10단계 / 모기 10단계 / 나방 10단계 / 혼합 웨이브 10단계
- 장총 중심 전투
- 발사음 / 명중음 / 실패음 / 클리어음 반영
- GitHub Actions APK 빌드 workflow 포함

## 빌드 방법
1. GitHub 저장소 루트에 전체 파일 업로드
2. `main` 브랜치 푸시
3. Actions > `Build Android APK` 실행
4. Artifact에서 `HAECHUNG_BAKMYEOL_V1.0.0_FINAL_MASTER.apk` 다운로드
