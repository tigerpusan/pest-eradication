# 해충 박멸 V0.1.7

고퀄 아트 에셋 반영 패치입니다.

## 핵심 변경
- CSS 도형 중심 비주얼을 이미지 에셋 중심 구조로 교체
- 파리 / 모기 / 나방 / 총기 그래픽을 PNG 아트 에셋으로 반영
- 게임 배경을 단순 색 면이 아닌 일러스트 배경으로 교체
- 홈 화면에 스토리 비주얼과 해충 단계 카드를 추가
- 기존 파리 → 모기 → 나방 → 혼합 웨이브 구조 유지
